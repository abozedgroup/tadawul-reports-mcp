# تصميم النظام: قاعدة إفصاحات تداول

آخر تحديث: 2026-09-30. هذه الوثيقة نتيجة جلسة أسئلة وقرارات، وهي المرجع لكل ما يُبنى بعدها.

## الهدف

قاعدة بيانات كاملة لإفصاحات الشركات المدرجة في السوق المالية السعودية (القوائم المالية مع إيضاحاتها، تقارير مجلس الإدارة، نشرات الإصدار، الإعلانات الجوهرية)، تُجمع آلياً من موقع تداول، ويصل إليها Claude عبر خادم MCP للبحث والمقارنة والتحليل.

## الحزمة التقنية

- **الاستضافة**: Railway Hobby. خدمة Node.js واحدة تشغّل خادم MCP وعامل الجلب (مهمة مجدولة داخلية).
- **قاعدة البيانات**: Postgres + pgvector على Railway (قالب pgvector).
- **الملفات**: Railway Storage Bucket (متوافق مع S3) للـPDF الأصلية.
- **النص**: استخراج مباشر من PDF النصية (مجاني). OCR فقط للصفحات الممسوحة (أقل من ٥٠ حرفاً مستخرجاً) بنموذج `google/gemini-2.5-flash-lite` عبر OpenRouter.
- **الاستخراج المهيكل**: نفس النموذج بمخطط JSON، مع تحقق حسابي (الموجودات = المطلوبات + حقوق المساهمين، وغيرها)؛ الفشل يُعاد بنموذج أقوى.
- **التضمين**: `voyageai/voyage-4-lite` عبر نقطة `/api/v1/embeddings` في OpenRouter (نحو ٠٫٠٢ دولار لكل مليون رمز؛ التحميل الأول كله أقل من دولار). مفتاح OpenRouter واحد يغطي OCR والاستخراج والتضمين.
- **الجلب**: طلبات HTTP مباشرة لنقاط JSON في تداول، ثم تحميل PDF من `/Resources/fsPdf/`.

## حقائق عن موقع تداول (تحقق بتاريخ 2026-09-30)

- قوائم الشركات والإعلانات تُحمّل بطلبات POST تعيد JSON (`getCompanyListByMarknetAndSectors`، `getAnnouncementListData` مع تصفية بالرمز والسوق والنوع والتاريخ والترقيم).
- صفحة تفاصيل الإعلان HTML خادمي: `issuer-announcements-details/?anId=…&cs=…&locale=en|ar`، وفيها جدول Element List ورابط PDF.
- PDF تحت `/Resources/fsPdf/{anId}_{companyId}_{date}_{time}_{en|ar}.pdf`؛ العربية والإنجليزية ملفان منفصلان.
- نحو ٢٣ إعلاناً يومياً؛ الأرشيف إلى 2001؛ PDF إلى 2020 على الأقل.
- العينات المفحوصة كلها PDF نصية؛ الممسوحة متوقعة في الملفات الأقدم وصفحات المراجعين ونشرات الإصدار (١٠ إلى ٢٠٪).
- الحماية: Akamai وWAF من نوع F5؛ لا RSS ولا API عامة. eReference Data (٥٠ ريال شهرياً) نظام ويب لا API. Argaam API من ٢٢٬٥٠٠ ريال سنوياً.

## المراحل

1. **الأساس**: مخطط Postgres، نقل الأدوات الحالية، خادم MCP بـ HTTP ومفاتيح، نشر على Railway.
2. **الجلب**: فهرسة الشركات والإعلانات من JSON تداول، تحميل PDF إلى Bucket، ١٠ شركات تجريبية.
3. **المعالجة**: استخراج النص، OCR الاحتياطي، التقطيع والتضمين، أدوات البحث الدلالي.
4. **الاستخراج المهيكل**: Element List ثم LLM للقوائم المالية، مع التحقق.
5. **التوسع**: السوق الرئيسية كاملة، المهمة اليومية، المراقبة.

## ما هو خارج النطاق الآن

مواقع الشركات، سوق نمو، أسعار الأسهم، واجهة ويب، البنود الخاصة بالبنوك، الجلب اللحظي.
