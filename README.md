# tadawul-reports-mcp

خادم MCP يحفظ التقارير المالية للشركات المدرجة في السوق المالية السعودية (تداول) في قاعدة بيانات SQLite محلية، ويتيح لـ Claude البحث فيها ومقارنتها وتحليلها.

## المتطلبات

- Node.js 22.5 أو أحدث (يستخدم `node:sqlite` المدمج، فلا حاجة لمكتبات أصلية)

## التثبيت

```bash
npm install
npm run build
npm run seed          # يضيف قائمة أولية من الشركات الكبرى (data/companies.json)
```

قاعدة البيانات تُحفظ في `data/tadawul.db`، ويمكن تغيير المسار بالمتغير `TADAWUL_DB_PATH`.

## الربط مع Claude

### Claude Code

```bash
claude mcp add tadawul-reports -e TADAWUL_DB_PATH=/المسار/الكامل/data/tadawul.db -- node /المسار/الكامل/dist/index.js
```

### Claude Desktop

في ملف `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "tadawul-reports": {
      "command": "node",
      "args": ["/المسار/الكامل/tadawul-reports-mcp/dist/index.js"],
      "env": { "TADAWUL_DB_PATH": "/المسار/الكامل/tadawul-reports-mcp/data/tadawul.db" }
    }
  }
}
```

## الأدوات

| الأداة | الوظيفة |
|---|---|
| `search_companies` | البحث بالرمز أو الاسم أو القطاع |
| `list_sectors` | القطاعات وعدد الشركات فيها |
| `list_metrics` | البنود المالية المدعومة |
| `upsert_company` | إضافة شركة أو تحديثها |
| `add_report` | إضافة تقرير (أو استبداله لنفس الشركة والسنة والفترة) |
| `get_report` | بنود التقرير مع النسب المحسوبة |
| `list_reports` | قائمة التقارير مع التصفية |
| `delete_report` | حذف تقرير |
| `compare_companies` | مقارنة عدة شركات في نفس الفترة |
| `metric_history` | تطور بند مالي عبر السنوات |
| `query_sql` | استعلام SELECT للقراءة فقط |

الفترات: `Q1` `Q2` `Q3` `Q4` `H1` `9M` `FY`.

البنود: الإيرادات، إجمالي الربح، الربح التشغيلي، صافي الربح، ربحية السهم، إجمالي الموجودات والمطلوبات وحقوق المساهمين، التدفق النقدي التشغيلي، النفقات الرأسمالية، توزيعات السهم.

النسب المحسوبة تلقائياً: هامش إجمالي الربح، الهامش التشغيلي، الهامش الصافي، العائد على حقوق المساهمين، العائد على الأصول، المطلوبات إلى حقوق المساهمين، التدفق النقدي الحر.

## إدخال البيانات

لا يحتوي المشروع على أرقام مالية جاهزة؛ أدخلها من القوائم المالية المنشورة في موقع تداول أو مواقع الشركات بإحدى طريقتين:

1. **عبر Claude**: أرفق القوائم المالية واطلب منه إضافتها باستخدام `add_report`.
2. **من ملف JSON**: `npm run import -- ملف.json` بالصيغة الموضحة في `data/example-import.json` (الأرقام فيه وهمية للتوضيح).
